# AD Tube | دانلودر یوتیوب

> ساخته‌شده با ❤ توسط **AD**

با این برنامه فقط لینک ویدیو را می‌دهید و ویدیو روی کامپیوتر خودتان ذخیره می‌شود.
هر جا که بخواهید می‌توانید محل ذخیره را انتخاب کنید و پیشرفت دانلود را هم می‌بینید.

---

## قبل از شروع، این دو چیز را داشته باشید

1. **پایتون** روی کامپیوتر نصب باشد (برنامه‌ای رایگان).
2. **VPN روشن باشد.** یوتیوب در ایران فیلتر است و بدون VPN دانلود انجام نمی‌شود.

---

## مرحله ۱: نصب پایتون (فقط یک بار)

اگر پایتون دارید، این مرحله را رد کنید.

1. به آدرس <https://www.python.org/downloads/> بروید و دکمه زرد **Download Python** را بزنید.
2. فایل را باز کنید.
3. **مهم:** در پایین پنجره نصب، تیک **Add python.exe to PATH** را بزنید.
4. روی **Install Now** کلیک کنید و صبر کنید تا تمام شود.

---

## مرحله ۲: اجرای برنامه

### روش آسان (ویندوز)

1. VPN خود را روشن کنید.
2. در پوشه برنامه، روی فایل **run.bat** دو بار کلیک کنید.
3. یک پنجره سیاه باز می‌شود. دفعه اول چند دقیقه صبر کنید، چون برنامه چیزهای لازم را نصب می‌کند (به اینترنت نیاز دارد).
4. مرورگر خودش باز می‌شود. اگر باز نشد، این آدرس را در مرورگر بنویسید:

   ```
   http://127.0.0.1:5000
   ```

### روش دستی (ویندوز، مک و لینوکس)

پنجره Terminal یا CMD را در پوشه برنامه باز کنید و این دستورها را بزنید:

```
pip install -r requirements.txt
python main.py
```

(در ویندوز اگر `python` کار نکرد، به‌جای آن `py` بنویسید.)
بعد آدرس `http://127.0.0.1:5000` را در مرورگر باز کنید.

---

## مرحله ۳: دانلود ویدیو

1. لینک ویدیوی یوتیوب را کپی کنید و در کادر اول بچسبانید.
2. اگر می‌خواهید ویدیو جای خاصی ذخیره شود، دکمه **انتخاب پوشه** را بزنید و پوشه را انتخاب کنید.
   اگر هیچ پوشه‌ای انتخاب نکنید، ویدیو در پوشه‌ای به نام `downloads` کنار برنامه ذخیره می‌شود.
3. دکمه **دانلود** را بزنید.
4. نوار قرمز کم‌کم پر می‌شود و حجم، سرعت و زمان باقی‌مانده را نشان می‌دهد.
5. وقتی پیام سبز «دانلود شد» آمد، ویدیو آماده است. مسیر فایل زیر نوار نوشته شده است.

برای بستن برنامه، پنجره سیاه را ببندید.

---

## اگر مشکلی پیش آمد

| پیام یا مشکل | چه کار کنم |
|---|---|
| **اتصال به یوتیوب برقرار نشد** | مطمئن شوید VPN روشن و وصل است. بعد دوباره امتحان کنید. |
| با اینکه VPN روشن است باز هم همین پیام می‌آید | بخش «تنظیمات پیشرفته» را پایین ببینید. |
| پنجره سیاه می‌گوید پایتون نصب نیست | مرحله ۱ را انجام دهید و تیک **Add python.exe to PATH** را حتماً بزنید. |
| `run.bat` باز می‌شود و فوراً بسته می‌شود | از «روش دستی» استفاده کنید تا پیام خطا را ببینید و برای ما بفرستید. |
| ویدیو خصوصی است یا پیدا نشد | لینک را بررسی کنید. ویدیوهای خصوصی دانلود نمی‌شوند. |
| دانلود کند است | سرعت به VPN و اینترنت شما بستگی دارد. |

---

## تنظیمات پیشرفته (معمولاً لازم نیست)

برنامه خودش مسیر VPN شما را پیدا می‌کند، پس این بخش را معمولاً **خالی بگذارید**.

فقط اگر VPN روشن است ولی پیام «اتصال به یوتیوب برقرار نشد» می‌آید، این کار را بکنید:

1. برنامه VPN خود را باز کنید و در تنظیماتش دنبال **پورت پروکسی** (Local port / HTTP port / SOCKS port) بگردید. یک عدد است، مثلاً `10808`.
2. در برنامه، «تنظیمات پیشرفته» را باز کنید.
3. در کادر بنویسید `127.0.0.1:` و بعد از آن همان عدد، مثلاً:

   ```
   127.0.0.1:10808
   ```
4. دوباره دانلود را بزنید.

## نکته‌ها

- ویدیو با بهترین کیفیت سازگار (تا ۱۰۸۰p) ذخیره می‌شود و به‌صورت **mp4** است.
- اگر لینک داخل یک پلی‌لیست باشد، فقط همان یک ویدیو دانلود می‌شود.
- این برنامه روی کامپیوتر خودتان اجرا می‌شود و چیزی به جایی فرستاده نمی‌شود.
- فقط ویدیوهایی را دانلود کنید که اجازه‌اش را دارید.
